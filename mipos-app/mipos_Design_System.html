04 — Reglas de Implementación

App (index.css)

/* Variables Globales App */
:root {
  --my-bg: #E0E8F2;
  --my-surface: #FFFFFF;
  --my-border: #C9D6E5;
  --my-text: #101828;
  --my-brand: #009B65;
}
[data-theme="dark"] {
  --my-bg: #080C12;
  --my-surface: #0F1821;
  --my-border: #1C2B3C;
  --my-text: #C8DCF0;
  --my-brand: #00D68F;
}

La app utiliza Tailwind V4 con @theme importando estas variables, permitiendo usar `bg-surface`, `text-brand`, etc.

Landing (style.css)

/* Variables Globales Landing */
:root {
  --bg: #E0E8F2;
  --surface: #FFFFFF;
  --line: #C9D6E5;
  --ink: #101828;
  --brand: #FF5252;
}
:root.dark-theme {
  --bg: #0C1827;
  --surface: #112136;
  --line: #1E3A5F;
  --ink: #E2E8F0;
  --brand: #FF5252;
}

La Landing utiliza CSS Vanilla. Se aplican las variables var(--bg), var(--surface) directamente sobre las clases en lugar de utilidades.
